# MiniGrid 局部视觉导航中的世界模型与情境记忆

本项目在 MiniGrid 中检验两个问题。第一，用世界模型预测候选动作的下一步视觉特征，能否比行为克隆取得更好的导航结果？第二，在模型权重和初始记忆相同的条件下，允许测试时写入记忆会怎样改变动作和导航结果？

实验借鉴 NavMorph 的动作条件预测与情境记忆（Contextual Evolution Memory，CEM）。智能体接收局部 RGB 图像、目标颜色和上一步实际执行的动作，在左转、右转和前进中选择。实验结论适用于这个三色目标、离散动作的 MiniGrid 设置。 [NavMorph 论文，Yao、Gao 与 Xu，ICCV 2025](https://arxiv.org/abs/2506.23468)

[实验报告](docs/实验报告.pdf) · [评测配置](正式评测结果/配置.json) · [结果汇总](正式评测结果/汇总.csv)

## 实验设计

| 组别 | 方法 |
| --- | --- |
| A | 行为克隆。根据当前视觉特征、目标和动作历史给候选动作打分 |
| B | 循环状态空间模型（RSSM）。预测各候选动作对应的下一步视觉特征，用于动作打分 |
| C | RSSM + CEM。在打分时检索和融合记忆，并在测试回合内更新记忆 |
| D | 使用 C 组对应种子的权重及初始记忆，保留检索和融合，关闭测试回合内的记忆写入 |

训练、验证和测试按地图几何布局分组，分别使用 128、24 和 48 组互不重叠的布局。A、B、C 各训练三个种子，并在验证集上选择权重。正式评测中，四组每个种子都运行同一批 288 条测试任务，共计 3,456 个闭环回合。

## 主要结果

下表为三个种子的均值。

| 方法 | 成功率 | 网格 SPL | 动作效率 |
| --- | ---: | ---: | ---: |
| A · 行为克隆 | **24.54%** | **0.1991** | **0.1854** |
| B · RSSM | 18.06% | 0.1530 | 0.1512 |
| C · RSSM + CEM，测试时读写 | 19.56% | 0.1659 | 0.1577 |
| D · RSSM + CEM，测试时只读 | 19.56% | 0.1659 | 0.1577 |

- **闭环导航。** 在本实验的任务和训练预算下，行为克隆的成功率最高。
- **开环预测。** 在相同起点和固定动作序列下，RSSM + CEM 模型的一步特征预测 MSE 为 **4.18**，单独 RSSM 为 **5.79**。预测误差和闭环成功率需要分别评估。 [多步预测误差图](docs/第22天_多步预测误差.png)
- **在线记忆写入。** C、D 的 864 对回合中有 **9 对**动作序列不同。逐任务成功标志和网格 SPL 一致。一个代表性案例中，两组在第二步选择了不同动作，C 最终踩错目标，D 则反复撞墙直至超时。 [代表轨迹图](docs/第22天_代表轨迹对照.png) · [三类失败案例](docs/第23天_三类实际失败.png)

## 可选 · 用保存的权重核对结果

原实验环境为 Windows、Python 3.14.3、PyTorch 2.14.0+cu130、Gymnasium 1.4.0、MiniGrid 3.2.0、NumPy 2.4.4，使用 NVIDIA GeForce RTX 4060 Laptop GPU。PyTorch 的安装方式按本机平台选择。 [PyTorch 安装指南](https://pytorch.org/get-started/locally/)

激活 Python 环境后，在仓库根目录运行下列命令。它会让四组分别用三个种子评测同一条测试任务，并将结果写入新的目录。

```bash
python -X utf8 -c "from pathlib import Path; from 正式评测 import run; run(Path.cwd(), Path('正式评测抽查'), limit=1)"
```

每次运行使用一个尚未存在的输出目录。完整评测使用同一入口，去掉 `limit=1` 即可。仓库中的固定清单、编码器和权重可直接用于评测。从已有特征开始重新训练导航模型时，使用实验交付包里的训练与验证特征。
